# Entrega Serify

## Contenido incluido

- Implementación Room con enfoque offline-first.
- Firebase Authentication y Firestore.
- Chat IA y persistencia de recomendaciones.
- 15 tests unitarios locales.
- 3 tests instrumentados de Room.
- Profiler Report en `docs/PROFILER_REPORT.pdf`.
- Guía de pruebas en `docs/TESTING.md`.

## Comandos de validación

```text
gradlew.bat testDebugUnitTest
gradlew.bat connectedDebugAndroidTest
```

El segundo comando requiere un emulador o dispositivo conectado.
